Requirements
============

`dosh(1)`_ is a `bash`_ script; it requires *bash(1)* 4.2 or later on the host.

*Note*: The shell interpreter run in the container does not need to be
*bash(1)*; it defaults to ``/bin/sh`` (see
:ref:`DEFAULT SHELL INTERPRETER <default-shell-interpreter>`).
