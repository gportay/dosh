== NAME

dosh - run a user shell in a container with the working directory bind mounted

== SYNOPSIS

Typical shell commands:

*dosh*    [(-|\+)abefhmnuvxC] [(-|+)o shopt] [SCRIPT_FILE  [ARGS...]]

*dosh* -c [(-|\+)abefhmnuvxC] [(-|+)o shopt] COMMAND [NAME [ARGS...]]

*dosh* -i [(-|\+)abefhmnuvxC] [(-|+)o shopt] [SCRIPT_FILE  [ARGS...]]

*dosh* -s [(-|\+)abefhmnuvxC] [(-|+)o shopt]               [ARGS...]

Advanced dosh container commands:

*dosh* --detach [OPTIONS]

*dosh* --exec CONTAINER [OPTIONS] [ARGS...]

*dosh* --attach CONTAINER [OPTIONS]

Advanced dosh image management commands:

*dosh* --tag

*dosh* --ls

*dosh* --gc [DOCKER_RMI_OPTIONS]

*dosh* --rmi [DOCKER_RMI_OPTIONS]

Extra docker front-end commands:

*dosh* --attach CONTAINER [DOCKER_ATTACH_OPTIONS]

*dosh* --kill   CONTAINER [DOCKER_KILL_OPTIONS]

*dosh* --rm     CONTAINER [DOCKER_RM_OPTIONS]

== DESCRIPTION

*dosh* is a sh-compatible front-end for *docker(1)* that executes commands read
from the standard input or from a file.

It runs a shell process in a new container with its own file system, the
current _working directory_ bind mounted, and the current _user/group_
privileges set.

When called without arguments, *dosh* defaults to running an interactive shell
as the current _user_.

When a container shell is started, *dosh* reads and executes commands from
_~/.dosh_profile_, if that file exists. This may be inhibited by using the
option *--no-doshprofile*.

When a container shell is started, *dosh* reads and executes commands from
_./doshrc_, if that file exists. This may be inhibited by using the option
*--no-doshrc*.

*dosh* builds and runs images for another _platform_ if the option *--platform*
is set to a target different from the host platform. Official _platforms_ are
listed in the section *PLATFORMS*.

*dosh* has specific options to modify its behaviour: the option *--dockerfile*
specifies the path to the *Dockerfile(5)* to use; the option *--home* bind
mounts the user's home directory instead of the _working directory_; the option
*--root* runs the container with _root_ privileges. Other options are described
in the section *OPTIONS*.

*dosh* keeps track of the built _docker images_, and of the path and content of
the _Dockerfiles_ read. It tags the _docker images_ using the *$USER*, the
*Dockerfile(5)* checksum computed at build time, and the _platform_ if set; the
tag is described in the section *TAG*. Multiple _docker images_ exist for the
same *Dockerfile(5)* in the file system if its content changes.

The option *--tag* outputs the _dosh image_ tag and exits. The options *--ls*
and *--rmi* exit immediately after, respectively, listing all of the user's
_dosh images_ and removing the latest _dosh image_ for the given
*Dockerfile(5)*, if it is built. The option *--gc* prunes the unused _dosh
images_ (*Deleted* and *Outdated*) and exits immediately. Statuses are described
in the section *STATUS*.

Under the hood, *dosh* automatically builds and tags a _docker image_ using the
*Dockerfile(5)* from the _current working directory_ through *docker-build(1)*.
It appends extra _RUN_ instructions to add the host _$USER/$GROUPS_ to the
_docker image_ through *groupadd(8)* and *useradd(8)*. Once the image is built,
*dosh* runs the *$SHELL* entry point, with the arguments given on the command
line, through *docker-run(1)*.

== OPTIONS

*POSIX shell related options:*

**-c**::
	Read commands from the command line.

**-i**::
	Set interactive.

**-s**::
	Read commands from the standard input.

**-abefhmnuvxC** or **-o shopt**, **+abefhmnuvxC** or **+o shopt**::
	For a more thorough description of shopts, please refer to sh help.

*Bash specific options:*

**-klprtBDEHIPT** or **-O shopt**, **+klprtBDEHIPT** or **+O shopt**::
	For a more thorough description of shopts, please refer to bash help.

*Dash specific options:*

**-pqEIV**, **+pqEIV**::
	For a more thorough description of shopts, please refer to dash help.

*Zsh specific options:*

**-0123456789dgklprtwyBDEFGHIJKLMNOPQRSTUVWXYZ**, **+0123456789dgklprtwyBDEFGHIJKLMNOPQRSTUVWXYZ**::
	For a more thorough description of shopts, please refer to zsh help.

*Docker related options:*

**--dockerfile FILE**::
	Path to the Dockerfile to use.

**--platform TARGET**::
	Set target platform.

**--context TAR**::
	Path to the context to send to the docker daemon.

**--no-auto-context**::
	Disable the automatic context sent to the docker daemon.

**--no-extra-options**::
	Disable extra options given to docker commands.

**--no-doshprofile**::
	Disable reading of ~/.dosh_profile.

**--no-doshrc**::
	Disable reading of ./doshrc.

**--rc FILE[,FILE]**::
	Read file(s).

**--directory DIR**::
	Change to the directory before doing anything else.

**--cache-directory DIR**::
	Cache directory tracking images.

**--working-directory DIR**::
	Working directory inside the container.

**--sudo**::
	Run docker with sudo.

**--root**::
	Run as root.

**--dind**::
	Run dosh in dosh.

**--groups**::
	Run with host groups.

**--home**::
	Bind mount the home directory.

**--parent**::
	Bind mount the parent directory.

**--mount-options OPTIONS**::
	Set the bind mount volume options.
	For a more thorough description, please refer to the docker-run(1) manual.

**--shell SHELL**::
	Set the shell interpreter.
	Equivalent to setting DOSHELL=<SHELL>.

**--tag**::
	Print the docker tag and exit.

**--ls**::
	List images and exit.

**--gc**::
	Clean up unused images and exit.

**--build-only**::
	Build the image if needed and exit.

**--build**::
	Build the image.

**--rebuild**::
	Build the image again, verbosely.
	Equivalent to --build --verbose.

**--rmi**::
	Remove the image and exit.

**--detach**::
	Detach the container.

**--exec CONTAINER**::
	Execute in the container.

**--attach CONTAINER**::
	Attach to the container.

**--kill CONTAINER**::
	Kill the container.

**--rm CONTAINER**::
	Remove the container.

**--dry-run**::
	Do nothing; echo docker commands.

*Miscellaneous options:*

**--verbose**::
	Turn on verbose mode.

**--version**::
	Print version.

**--help**::
	Print usage.

== ENVIRONMENT VARIABLES

**DOSHELL**::
	The full pathname to the shell to run in the docker image.
	Equivalent to --shell <SHELL>.

**DOSHRC**::
	Read file(s).
	Equivalent to --rc <FILES>.

**DOSHLVL**::
	Incremented by one each time an instance of dosh is started.

**DOSH_SUDO**::
	Set sudo command.

**DOSH_DOCKER**::
	The docker executable.

**DOSH_DOCKER_HOST**::
	The docker daemon socket to connect to.

**DOSH_DOCKERFILE**::
	The filename of the Dockerfile to use.
	Equivalent to --dockerfile <FILE>.

**DOSH_PLATFORM**::
	The target platform to use.
	Equivalent to --platform <TARGET>.

**DOSH_MOUNT_OPTIONS**::
	Set the bind mount volume options.
	Equivalent to --mount-options <OPTIONS>.

**DOSH_DOCKER_RUN_EXTRA_OPTS**::
	Set additional parameters to the docker run command.

**DOSH_DOCKER_EXEC_EXTRA_OPTS**::
	Set additional parameters to the docker exec command.

**DOSH_DOCKER_ATTACH_EXTRA_OPTS**::
	Set additional parameters to the docker attach command.

**DOSH_DOCKER_KILL_EXTRA_OPTS**::
	Set additional parameters to the docker kill command.

**DOSH_DOCKER_RM_EXTRA_OPTS**::
	Set additional parameters to the docker rm command.

**DOSH_DOCKER_BUILD_EXTRA_OPTS**::
	Set additional parameters to the docker build command.

**DOSH_DOCKER_RMI_EXTRA_OPTS**::
	Set additional parameters to the docker rmi command.

**./doshrc**::
	The local initialization file.

**$XDG_CACHE_HOME/dosh**, **~/.cache/dosh**::
	The user cache directory tracking _dosh images_ and _Dockerfiles_.

== TAG

*dosh* names the _docker images_: _dosh-$USER-$dockerfile_checksum[-$platform]_.

== STATUS

**Untracked**::
	Image whose *Dockerfile(5)* has been untracked since it was built.

**Deleted**::
	Image whose *Dockerfile(5)* has been removed since it was built.

**Outdated**::
	Image whose *Dockerfile(5)* has changed since it was built.

**Ready**::
	Image whose *Dockerfile(5)* is unchanged since it was built.

**Running**::
	Image whose *Dockerfile(5)* is unchanged since it was built, with a
	container running.

== EXAMPLES

Run an _interactive shell_ in the latest _Ubuntu_ container:

	$ echo "FROM ubuntu" >Dockerfile
	$ cat Dockerfile
	FROM ubuntu

	$ dosh
	sha256:777c682a9816
	gportay@4c3fb2d195d8:~$ 

Check the _distribution_:

	gportay@4c3fb2d195d8:~$ cat /etc/os-release
	DISTRIB_ID=Ubuntu
	DISTRIB_RELEASE=16.04
	DISTRIB_CODENAME=xenial
	DISTRIB_DESCRIPTION="Ubuntu 16.04.1 LTS"
	NAME="Ubuntu"
	VERSION="16.04.1 LTS (Xenial Xerus)"
	ID=ubuntu
	ID_LIKE=debian
	PRETTY_NAME="Ubuntu 16.04.1 LTS"
	VERSION_ID="16.04"
	HOME_URL="http://www.ubuntu.com/"
	SUPPORT_URL="http://help.ubuntu.com/"
	BUG_REPORT_URL="http://bugs.launchpad.net/ubuntu/"
	VERSION_CODENAME=xenial
	UBUNTU_CODENAME=xenial

Check the _user_:

	gportay@4c3fb2d195d8:~$ whoami
	gportay

Exit the container:

	gportay@4c3fb2d195d8:~$ exit
	logout

Run the _commands_ above in the same container as a _shell_ script:

	$ dosh -c "cat /etc/os-release && whoami"
	NAME="Ubuntu"
	VERSION="16.04.1 LTS (Xenial Xerus)"
	ID=ubuntu
	ID_LIKE=debian
	PRETTY_NAME="Ubuntu 16.04.1 LTS"
	VERSION_ID="16.04"
	HOME_URL="http://www.ubuntu.com/"
	SUPPORT_URL="http://help.ubuntu.com/"
	BUG_REPORT_URL="http://bugs.launchpad.net/ubuntu/"
	VERSION_CODENAME=xenial
	UBUNTU_CODENAME=xenial
	gportay
	logout

Check the _PWD_ bind mount; write the _distribution_ name to a local file:

	$ dosh -c "grep '^NAME=' /etc/os-release >os-release"

Read the contents outside the container:

	$ cat os-release
	NAME="Ubuntu"

Specify the *Dockerfile(5)* to use:

	$ dosh --dockerfile docker/tests/Dockerfile.fedora -c "grep '^NAME=' /etc/os-release"
	sha256:44d9de323a55
	NAME=Fedora

Change to another _directory_ before doing anything else:

	$ cd /tmp
	$ dosh --directory "$OLDPWD" -c "grep '^NAME=' /etc/os-release"
	NAME="Ubuntu"
	$ cd -

Run the shell as _root_ with _--root_ to perform privileged operations in the
container:

	$ dosh --root
	root@4c3fb2d195d8:/# whoami
	root
	root@4c3fb2d195d8:/# apt-get install -y asciidoctor
	Reading package lists... Done
	Building dependency tree
	Reading state information... Done
	asciidoctor is already the newest version (1.5.4-1).
	0 upgraded, 0 newly installed, 0 to remove and 6 not upgraded.

Rebuild the image if the *Dockerfile(5)* has changed:

	$ echo "RUN apt-get update && apt-get install -y asciidoctor" >>Dockerfile
	$ cat Dockerfile
	FROM ubuntu
	RUN apt-get update && apt-get install -y asciidoctor
	$ dosh --build
	sha256:777c682a9816
	gportay@31dd533203ea:~$ which asciidoctor
	/usr/bin/asciidoctor
	gportay@31dd533203ea:~$ exit
	logout

	$ dosh
	gportay@0406c4779648:~$ exit
	logout

Bind mount the _$HOME_ directory:

	$ echo $PWD
	/home/gportay/src/dosh
	$ echo $HOME
	/home/gportay

	$ dosh --home
	gportay@098ac1e92f20 ~/src/dosh $ echo $PWD
	/home/gportay/src/dosh
	gportay@098ac1e92f20 ~/src/dosh $ echo $HOME
	/home/gportay

Use _/bin/sh_ as the default _$SHELL_:

	$ echo $0
	bash

	$ dosh --shell /bin/sh
	$ echo $0
	/bin/sh
	$ dosh --shell /bin/bash
	gportay@a6d7f01cd20f:~/src/dosh $ echo $0
	/bin/bash

Detach a container:

	$ dosh --detach
	6b0e5f883ca5e176452bb234bccf70623a35b5d5f12ae56761a392a3e9f40125

	$ docker ps -a
	CONTAINER ID        IMAGE                                                                  COMMAND                  CREATED             STATUS              PORTS               NAMES
	6b0e5f883ca5        dosh-dbc94874ef3f1be8f595c79fcaf36fd691dc2af3b7b29f291210cecc8f2beca2  "/bin/bash -c 'cd /ho"   7 seconds ago       Up 6 seconds                            determined_archimedes

Execute commands in it with _--exec_:

	$ dosh --exec determined_archimedes -c 'hostname'
	6b0e5f883ca5

Attach to it using _--attach_:

	$ dosh --attach determined_archimedes
	gportay@6b0e5f883ca5:~$ exit
	exit

Kill it using _--kill_:

	$ dosh --kill determined_archimedes
	determined_archimedes

And do not forget to remove it using _--rm_:

	$ dosh --rm determined_archimedes
	determined_archimedes

	$ docker ps -a
	CONTAINER ID        IMAGE                                                                  COMMAND                  CREATED             STATUS              PORTS               NAMES
